# CarDrivingSimulatorVR

<img width="1825" height="870" alt="image" src="https://github.com/user-attachments/assets/294a697b-d9b6-4d71-add3-4e528f55a571" />

An **interactive virtual reality driving simulation** designed to replicate basic real-world vehicle interaction.  
The project focuses on immersive interaction with a vehicle, allowing the user to operate core car functions naturally inside a VR environment.

The simulation demonstrates how common vehicle controls can be implemented in VR, providing a foundation for driving simulators, training tools, or interactive VR experiences.

---

## Features

### Vehicle Interaction

#### Openable Car Doors
Each door can be opened and closed through VR interaction, mimicking real-world behavior.

#### Keyless Ignition System
The vehicle can be started and turned off without a physical key, similar to modern push-start systems.

---

### Driving Controls

#### Automatic Gearbox
The vehicle uses an automatic transmission, allowing users to focus on steering and acceleration.

#### Steering Wheel Physics
- Fully interactive steering wheel
- Automatically returns to the **center position** when released
- Simulates realistic steering feedback

---

### Mirrors

#### Side Mirrors
Functional mirrors positioned on both sides of the car to assist with spatial awareness.

#### Rearview Mirror
A central mirror providing visibility of the environment behind the vehicle.

---

## Requirements

- VR Headset (Meta Quest, HTC Vive, Valve Index, etc.)
- Motion controllers
- Compatible VR runtime (SteamVR / OpenXR)
